## 子票拆分草案 v1（待用户确认，尚未发布子票）
以下 T 编号是草案编号，不是 GitHub Issue 编号。按能力推进；母票仅跟踪。每票发布时补充 Scope、难度、验收条目及实际阻塞关系，超过 M 的发现先拆票再实施。

1. **T01：完整复制可追溯基线**
   - 阻塞：无。
   - 交付与验收：从固定提交复制所有 UI 表面、文档、设计资料和必要工程资产；盘点散落 UI 并保存原始材料，逐文件校验。原仓库零改动，不宣称已独立运行。

2. **T02：桌面基础与复合组件独立演示**
   - 阻塞：T01。
   - 交付与验收：在独立宿主中验证桌面表单、表格、弹窗、布局和主题；解除原仓库别名与样式路径依赖，保留公共组件能力。

3. **T03：触屏组件独立演示**
   - 阻塞：T02。
   - 交付与验收：使用中性数据演示触屏全部现有能力，验证触控尺寸、交互状态与主题，不依赖生产业务模型。

4. **T04：移动组件独立演示**
   - 阻塞：T02。
   - 交付与验收：移动包不依赖原 workspace 路径；演示弹层、输入和扫码交互，验证移动样式和键盘约束。

5. **T05：大屏组件独立演示与语义解耦**
   - 阻塞：T02。
   - 交付与验收：完整保留大屏缩放、布局、指标、图表、滚动和刷新能力，以通用输入/回调表达；验证不同视口和资源加载。

6. **T06：上传与文件预览能力独立交付**
   - 阻塞：T02。
   - 交付与验收：以宿主注入传输适配演示上传及失败/取消状态；验证 PDF、Office 等现有预览能力与运行资源，不依赖原后端。

7. **T07：排程可视化完整迁入并解耦业务模型**
   - 阻塞：T02。
   - 交付与验收：保留甘特图与资源调度等全部既有 UI 能力；通过通用模型和宿主适配移除业务 DTO/SDK 依赖。引擎及第三方许可限制如实记录。

8. **T08：散落 UI 与应用壳展示能力迁入**
   - 阻塞：T01。
   - 交付与验收：逐项处理盘点发现的 UI，提取展示与交互、保留宿主业务适配；每项有演示或明确处置依据，不能以业务耦合为由遗漏 UI。若超过 M 按实际能力拆后续子票。

9. **T09：完整文档站脱离 Nerv-IIP 运行**
   - 阻塞：T03、T04、T05、T06、T07、T08。
   - 交付与验收：文档站独立启动与构建，全部交互形态和公共组件有有效示例，无原业务包依赖，无静默删页缩减能力。

10. **T10：版本化安装产物与独立宿主验收**
   - 阻塞：T09。
   - 交付与验收：构建可安装产物，验证类型、样式、资源、依赖身份及代表性交互；产物消费禁止源码 alias。发布目标和凭据另按实际选定，不自动公开 npm。构建/CI 若需跨任务改造先细拆。

11. **T11：平台控制台接入新库**
   - 阻塞：T10。
   - 交付与验收：固定版本消费新库；在原应用执行受影响门禁及浏览器交互/视觉回归，可回退旧版本。

12. **T12：业务 PC 控制台接入新库**
   - 阻塞：T10。
   - 交付与验收：业务适配保留在应用，改为消费新库；覆盖表格、表单、文件、排程等实际使用能力并记录验收。

13. **T13：PDA 接入新库**
   - 阻塞：T10。
   - 交付与验收：消费新移动包并验证实际触控、输入、扫码链路；浏览器与设备证据分开，不将未运行设备验收视为通过。

14. **T14：大屏应用接入新库**
   - 阻塞：T10。
   - 交付与验收：消费新大屏能力，验证实际取数适配、显示、缩放、图表和刷新；数据计算仍由宿主负责。

15. **T15：退出旧库并完成迁移验收**
   - 阻塞：T11、T12、T13、T14。
   - 交付与验收：确认全部消费者切换后移除旧源码及迁走的文档、测试、配置与依赖；所有 UI 盘点项闭合，保留回退提交与来源证据。

## 待确认的验收接缝
以“仓库外独立 Vue 项目安装新库产物并在浏览器运行四种交互形态”为最高接缝；继承有价值的组件行为测试。Nerv-IIP 四个实际应用分别验收，不用文档站成功代替业务接入成功。

## 待审阅
请确认规格与验收接缝是否符合预期，以及上述颗粒度、阻塞关系是否合适，是否需要合并或拆细。确认后发布子票并从无阻塞 T01 开始复制。当前未执行组件复制、安装、构建或浏览器验收。
