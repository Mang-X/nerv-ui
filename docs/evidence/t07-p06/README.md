## 实现与兼容

唯一生产行为 owner 是 `DhtmlxEngine` order 手势与既有 TaskDragPayload 的 order 语义。沿用公开 `onBeforeTaskDrag` / `onBeforeTaskChanged(id, mode, originalTask)`：捕获当前 vendor 日期，返回 false 让 vendor 回退，离开原生 mouseup 栈后发提案，再按最新 model 重绘。期间 model/锁定/删除/readonly 使旧提案失效，卸载撤销 timer/listener；回调重入期间不启动第二个未结算手势。输入不写入，task/operation/resource 身份不猜测；父层回写才接受，不回写即拒绝，异步决定稍后提供新 model。

`readOnly=false` 默认、事件名、payload 字段保持，无新 API/类型字段。P04 已移除 useEngine 80ms 抑制，本票不恢复。resource 的既有 after-drag 路径保留，P07 负责资源改派；P08 面板、P09 draft/table、业务约束/权限/求解/SDK/保存均未提前。迁移规则与示例更新于 [renderer](../../scheduling-renderer.md#p06order-受控编辑) 和 [GanttChart](../../../frontend/apps/design-system/docs/components/desktop/gantt-chart.md)。入口 `/#schedule-edit/library`、`/#schedule-edit/studio`，可返回既有入口；用户文案不含接线/验收说明。
