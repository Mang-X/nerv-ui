NvRingGauge 环形仪表 ​

大屏上的环形进度指标，数值与弧长同步展示。

示例 ​

76%设备综合效率
92%一次合格率
45%任务进度
120%超限示例
0.5小时负载

API ​

NvRingGauge 属性 ​

属性说明类型默认
value当前值number—
max满量程值number100
size整体尺寸（px）number180
thickness圆环线宽（px）number14
tone语义色调accent | success | warning | dangeraccent
label圆环下方文字string—
unit数值单位string—
showValue显示中心数值booleantrue
ariaLabel无障碍标签stringlabel，否则 指标

说明 ​

value 超出 0 ~ max 时按边界截断绘制，中心数值仍按原值显示（整数值直出，非整数保留一位小数）。
