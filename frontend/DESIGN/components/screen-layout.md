# 种子氛围布局

## 规则

`NvScreenLayout` 仅组合固定 1920×1080 的淡色点阵、两条光路、彗星、星点、`NvScreenHeader` 与内容区域。点阵使用既有 `--nv-scr-line-2` 色彩并自顶部渐隐；固定来源的点阵层只有透明背景和 mask，未实际绘出点阵，本件补全该视觉缺口。宿主传稳定的 `seed`、页头文字和时间；组件不读取路由、不计时。需要随视口缩放时由宿主在外层使用 `NvScreenScaler`，不要再包一层布局框架。

## 判定

需要保留来源 `ScreenLayout` 的确定性氛围与 header/body 层次时使用此件。只要纯装饰流线或等距块体时使用对应背景件。不同 `seed` 改变可观察路径与星点；相同 `seed` 在不同实例中几何相同，而渐变与轨道 ID 保持实例隔离，包括同页的独立 Vue 应用根。SSR 初始标识沿用 Vue `useId()` 以便水合；挂载后补页内实例序号，避免多个应用根各自从 `v-0` 起步造成冲突。

## 正例

展厅大屏以展厅标识作为 `seed`，宿主传入挂钟字符串；内容插槽放入可点击的导览操作。纯装饰 SVG 默认穿透指针，内容按钮可直接操作。系统偏好低动效时彗星隐藏、星点静止，几何与内容仍在。

## 反例

不把 route、认证、业务状态或定时取时写进布局；不因同一 `seed` 复用 SVG ID，也不在组件内部叠加第二个缩放器。长内容应由内容区域滚动并由宿主保持可读字号。
