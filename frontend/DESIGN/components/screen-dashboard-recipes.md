# 大屏分栏 recipe 决策

C04 复用既有 Screen 原语，不增加导出。阅读活动是一个入口的报名与活动日历；展览安排是作品数量、布展窗口和多入口的组合。两者均为中性内存事实，不推导业务规则。

规则：固定高舞台、三列 minmax 分栏，动态消息用 ScrollBoard，人工处理的队列用 Table + Pagination。内滚区提供 Tab 焦点，长文字换行，编号独立等宽小字号。主 KPI 显示数字与单位，次 KPI 降一级；零不是未知。

判定：需要持续扫视使用自动滚动；需要定位记录使用静态分页。图和明细读取同一份当前 distribution，切换不保留旧数据副本。阈值与分层均为输入序列，不由组件解释行业含义。

正例：宿主拒绝 page/view 请求时仍显示既有权威状态；记录缩短时只将展示页夹到有效范围，不修改宿主输入。

反例：完整复制 warehouse 页、把失败当空、将过期当错误、把业务计算或请求框架塞进 UI 包。不得以 jsdom 测量声称浏览器可读性通过。
