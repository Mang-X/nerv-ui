# 大屏装饰背景

## 规则

`NvScreenFlowLinesBg` 与 `NvScreenIsometricBlocksBg` 只承担大屏舞台的背景装饰。宿主提供有尺寸且 `position: relative` 的容器和内容；组件的 SVG 绝对铺满容器，默认不接收指针事件，内容按钮仍由宿主操作。

## 判定

- 需要流动的线条、交汇节点与光点时选 `NvScreenFlowLinesBg`；需要稳定的等距网格与块体时选 `NvScreenIsometricBlocksBg`。两件都无需数据或必填属性，可在同页重复挂载。
- 背景本身固定为 screen 深色语汇，颜色走 `--nv-scr-*`。系统低动效会隐藏流光与扩散环并停止节点呼吸，线框、网格和块体继续可见。
- SVG 的 `class`、`style` 等宿主属性仍会透传；默认指针穿透来自组件样式，宿主显式覆写 `pointer-events` 时自行负责交互层级。

## 正例

在空间舞台的相对定位容器中，先放可点击的操作按钮，再放装饰背景；在不同尺寸区域各挂一个实例。按钮保持真实可点，背景按容器裁切。

## 反例

不要把背景当作按钮、图表、业务状态或路由入口；不要让装饰层挡住宿主按钮。无需为两件背景接入业务 SDK、权限或数据查询。
