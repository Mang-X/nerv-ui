# 可搜索多选实体判定

## 规则

`NvEntityMultiPicker` 属于 PC 指针表面的选择区块，复用 `NvEntityPicker` 的搜索框、列表和分页事件。宿主以数组持有选中值，组件只提出新数组；值按完整字符串比较，不拆逗号，也不修改输入。已选项以可移除标签展示，候选页中同 key 不再提供重复添加。

标签仅记住当前选中项曾见过的名称。换搜索结果页时保留，新结果同 key 时更新，移除后清退；从未见过的历史值原样显示，不能据此推断实体仍有效或有资格。搜索结果、晚回隔离、总数、权限及提交由宿主负责。

## 判定

只选一个目录实体时用 `NvEntityPicker`。需要从可搜索目录逐个加入、核对并移除多个已选实体时用 `NvEntityMultiPicker`。枚举单选仍用 `NvSearchSelect`；允许自由输入时用 `NvCombobox`。旧应用的逗号字段应在宿主边界转换，不让公共组件承担存储格式。

## 正例

宿主传当前页的中性 `value` 与 `label`，监听 `update:search` 取新页，收到 `load-more` 后追加当前查询的结果。宿主接受 `update:modelValue` 提案后更新受控数组；若值在当前页缺席，保留组件已见标签或重新提供该值的名称。

## 反例

把逗号串直接作为 `modelValue`；把 DTO、SDK、认证或查询函数放入组件；把历史未知值隐藏或标作失效；用当前页缺席来删除已选值；在组件内决定目录权限或处理晚到请求。
